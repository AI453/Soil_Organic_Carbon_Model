# Soil_Organic_Carbon_Model
Masters thesis modelling soil organic carbon using field data and sentinel 2 data
Uses a basic random forest regressor with a sparrow search algorithm to optimise parameters. Full report with additional research questions can be found [here] (https://drive.google.com/file/d/1E9AI75jrXylPi7vQanjmzVm8Z5t2b6Lr/view?usp=sharing)
